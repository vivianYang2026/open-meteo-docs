# Open-Meteo API sample documentation

Sample developer documentation for the [Open-Meteo Forecast API](https://open-meteo.com/),
a free weather API that requires no API key.

**Status:** In progress. Last updated November 26, 2026.

## Planned contents

- **Getting-started guide:** make your first request with curl and Python,
  read the response, and troubleshoot common errors.
- **API reference:** generated from an OpenAPI specification for the
  `/v1/forecast` endpoint.
- **How these docs were built:** testing process, style checks, and use of AI tools.

## Approach

- Every command and code sample is tested on Ubuntu (WSL) before publishing.
- Troubleshooting entries are based on real errors encountered during testing.
- Docs are written in Markdown and will be published with Docusaurus on GitHub Pages.
